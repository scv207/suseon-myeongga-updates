# 수선명가 업데이트

수선명가 매장 관리 프로그램의 Windows x64 배포 저장소입니다.

매장 기록·고객정보·비밀번호·PC 연결 설정은 포함하지 않습니다.

## 실행과 업데이트

최초 사용은 Releases의 suseon-myeongga.exe를 내려받아 실행하세요. 사용 중에는 프로그램의 업데이트 알림에서 새 버전을 설치할 수 있습니다.

오른쪽 위 X로 닫으면 프로그램과 모바일·외부 조회 연결이 함께 종료됩니다.

원본 자료는 실행 파일 옆 수선명가 데이터 폴더에 보관됩니다. 새 버전에서도 자료를 그대로 사용합니다.

정상 업데이트를 확인한 뒤 이전 실행 파일·다운로드 임시 파일을 자동 정리합니다. 이 저장소도 최신 배포만 유지합니다. 데이터와 자동 백업은 삭제하지 않습니다.

현재 배포: v1.3.1
